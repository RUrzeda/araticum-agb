# Biomassa aérea nas áreas de restauração do Araticum em Goiás

Site estático da plataforma: https://rurzeda.github.io/araticum-agb/

Mostra, para 49 polígonos de restauração da plataforma Araticum em Goiás, a imagem e o NDVI de cada ano de 2000 a 2024 (Landsat até 2016 e Sentinel-2 depois) e, só nos polígonos em que o modelo se aplica, o nível de biomassa aérea (AGB) do período e a AGB de cada ano de 2017 a 2024, sem tendência. A página `metodologia.html` explica o método e as limitações.

Este repositório tem só os arquivos do site. Eles foram montados a partir do commit `c68587e` (tag `v3.3`) do projeto de origem, metodologia versão 3, modelo com md5 `3279406c75587240a30cb7383496e502`. O arquivo `versao.json` traz o md5 de cada arquivo.
